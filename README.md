### To-Do List Management System
Developed a To-Do List application using Python and Tkinter, providing an intuitive interface for task management, including adding, viewing, searching, updating, and deleting tasks. This project demonstrates my ability to build interactive GUI applications and handle structured data effectively.

## Key Achievements

Built a user-friendly GUI with Tkinter for seamless task management

Implemented functionality to add, view, search, update, and delete tasks

Displayed tasks in a tabular format using PrettyTable for clear visualization

Integrated message boxes for user notifications and validation

Ensured smooth data handling and storage for daily task operations
